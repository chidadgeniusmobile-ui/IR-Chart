IR-Chart starter project

1) Install Node.js LTS on Windows.
2) Open Command Prompt in this folder and run:
   npm install
   npx expo install expo-image-picker react-native-url-polyfill @supabase/supabase-js
3) Copy .env.example to .env and add your Supabase Project URL and publishable key.
4) Create a Supabase project, run supabase-setup.sql in SQL Editor, and create a PUBLIC Storage bucket named post-images.
5) Start the app:
   npx expo start
6) To create an APK:
   npm install -g eas-cli
   eas login
   eas build:configure
   eas build -p android --profile preview

Important:
- Phone sign-in requires phone auth to be enabled and an SMS provider configured in Supabase.
- For email signup, configure email confirmation settings in Supabase.
- This is a starter, not a production-audited social network. Before public release, test all access policies, add reporting/blocking/moderation, and review privacy/security.
