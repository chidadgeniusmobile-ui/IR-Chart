# IR-Chart

Starter Android social app in React Native + Expo + Supabase.

Features in this starter:
- Email or phone/password sign-up and login
- User profile record
- Social feed with caption and photo posts
- People list and one-to-one text messaging
- Blue and white mobile UI
- EAS APK build configuration

Read `package-notes.txt` and `supabase-setup.sql` before running.
